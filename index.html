Citrus Yield Prediction System

Overview

项目概述

🎯

项目背景

面向重庆地区柑橘种植场景（奉节脐橙、忠县柑橘等），通过目标检测识别花朵和果实，结合生长阶段进行产量预测，并提供低产风险预警。

📋

项目约束

技术栈：Python 全栈（PyTorch + YOLOv8 + Gradio + SQLite）
团队规模：2-3人小组
需有自主功能设计和算法实现

🏆

项目目标

自动检测花朵、幼果、成熟果实
支持多阶段产量预测
提供低产风险预警
简洁易用的 Web 界面

核心目标

1 实现柑橘花朵、幼果、成熟果实的自动检测
2 支持不同生长阶段的产量预测（早期 → 中期 → 成熟）
3 提供低产风险预警功能
4 提供简洁易用的 Web 界面

Core Modules

核心功能模块

1

目标检测引擎

检测图片/视频帧中的柑橘花朵和果实
🌸

flower

花朵检测 — 用于早期产量预测

🟢

immature_fruit

幼果检测 — 用于中期修正

🍊

mature_fruit

成熟果实检测 — 用于成熟期矫正

模型微调流程

收集数据集 → LabelImg 标注 → YOLO 格式转换 → Fine-tune 50-100 epochs → 验证 mAP ≥ 0.7
2

生长阶段判断

根据检测结果自动判断当前生长阶段
🌸
花期

flower 占比 > 60%
花量 × 经验坐果率 × 平均果重

→
🟢
幼果期

immature_fruit 占比 > 50%
幼果数 × 成活率 × 平均果重

→
🍊
成熟期

mature_fruit 占比 > 50%
果实数 × 平均果重（矫正值）

3

产量预测算法

核心公式与品种参数配置
yield_estimate = detected_count × correction_factor × avg_fruit_weight
阶段correction_factor说明
🌸 花期坐果率 (~5-15%)视品种和气候
🟢 幼果期成活率 (~50-70%)落果后存活率
🍊 成熟期~1.0最终矫正
# 品种参数配置（可扩展） CITRUS_CONFIG = { "奉节脐橙": { "avg_weight_kg": 0.25, "flower_fruit_rate": 0.08, "immature_survival_rate": 0.60 }, "忠县柑橘": { "avg_weight_kg": 0.20, "flower_fruit_rate": 0.10, "immature_survival_rate": 0.65 }, }
4

风险预警

与历史同期数据对比，发出预警
⚠️
低产风险提示 — 当前检测数量 < 历史同期均值 × 0.8
🔴
严重低产预警 — 当前检测数量 < 历史同期均值 × 0.6
✅
产量正常 — 当前检测数量 ≥ 历史同期均值 × 0.8

无历史数据时，基于品种平均值的合理范围给出参考建议。

5

历史数据管理

SQLite 数据库表设计

orchard_info

果园/树木基本信息
名称 · 品种 · 树木数量 · 地理位置

detection_records

检测记录
图片路径 · 阶段 · 各类计数 · 预测产量 · 置信度 · 风险等级

history_yield

历史实际产量
年份 · 季节 · 实际产量(kg)

查看完整 SQL 建表语句
-- 果园/树木基本信息 CREATE TABLE orchard_info ( id INTEGER PRIMARY KEY, name TEXT, variety TEXT, tree_count INTEGER, location TEXT, created_at DATETIME ); -- 检测记录 CREATE TABLE detection_records ( id INTEGER PRIMARY KEY, orchard_id INTEGER, image_path TEXT, stage TEXT, flower_count INTEGER, immature_count INTEGER, mature_count INTEGER, predicted_yield REAL, confidence REAL, risk_level TEXT, detected_at DATETIME, FOREIGN KEY (orchard_id) REFERENCES orchard_info(id) ); -- 历史实际产量 CREATE TABLE history_yield ( id INTEGER PRIMARY KEY, orchard_id INTEGER, year INTEGER, season TEXT, actual_yield REAL, recorded_at DATETIME, FOREIGN KEY (orchard_id) REFERENCES orchard_info(id) );

风险与应对

风险应对措施
柑橘数据集不足使用数据增强 + 公开数据集组合 + 优先保证核心功能可用
模型精度不够适当增加训练轮次，调整 anchor，使用更大模型（YOLOv8s）
视频处理太慢降低采样帧率，使用 YOLOv8n（最快版本）
历史数据缺乏提供导入模板和示例数据，支持无历史数据模式
